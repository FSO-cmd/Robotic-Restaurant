Smart Food Delivery System

A modular food delivery solution featuring a feeding station and a dual-wagon mobile robot. Built on ESP32, the
system uses MQTT for real-time messaging, CAN Bus for reliable motor control, and a tablet-based web UI for
order management. Designed for performance, scalability, and seamless hardware-software integration.
